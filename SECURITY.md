# Security Policy

## Reporting vulnerabilities
Please do not publish vulnerabilities, credentials, or sensitive records in public issues.
Contact the repository owner privately through their GitHub profile or GitHub private vulnerability reporting (if enabled).

## Supported versions
Security fixes target the current main release only. No security guarantee is provided.

## Data handling
- Do not commit API tokens, credentials, private shop analytics, customer records, or .env files.
- Keep private research under research/private/ or outside this repository.
- Do not paste sensitive information into public AI prompts or issue reports.
- Review any downloaded scripts before running them.
- This toolkit does not require an Etsy API token for its included local calculators.
